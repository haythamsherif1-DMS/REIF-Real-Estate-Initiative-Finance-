# الأمنيات — إدارة الحفظ المركزي ومتابعة الوثائق والمستندات

واجهة النظام على GitHub Pages: شاشة بداية بلوجو **الأمنيات**، والنظام (Google Apps Script) بيفتح جوه نفس الصفحة،
وممكن تثبيته كتطبيق بأيقونة على الموبايل والكمبيوتر.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية: شاشة اللوجو المتحركة + فتح النظام |
| `manifest.json` | بيانات التطبيق (الاسم، الأيقونة، الألوان) للتثبيت |
| `sw.js` | بيخلي شاشة البداية والأيقونات تفتح بسرعة (النظام نفسه دايمًا من النت) |
| `icon.png` ، `icon-192.png` | أيقونة التطبيق |
| `icon-maskable-512.png` ، `icon-maskable-192.png` | أيقونة أندرويد (بتتقص دائرة/مربع حسب الموبايل) |
| `apple-touch-icon.png` | أيقونة الآيفون والآيباد |
| `favicon.svg` ، `favicon-64.png` | أيقونة تبويب المتصفح |
| `logo.svg` | اللوجو الكامل |

## خطوات الرفع

1. ارفع كل الملفات دي على الـ repository (استبدل الملفات القديمة بنفس الأسماء).
2. **Settings ← Pages ← Build and deployment**: اختار `Deploy from a branch`، والفرع `main` والمجلد `/ (root)` ← Save.
3. بعد دقيقة الرابط بيظهر فوق: `https://<اسم-الحساب>.github.io/<اسم-الريبو>/`

## مهم: إعداد Google Apps Script

علشان النظام يفتح جوه صفحة GitHub لازم النشر يكون بالإعدادات دي:

1. حدّث ملفات `Code.gs` و `App.html` و `Index.html` و `Styles.html` و `Setup.gs` و `appsscript.json` بالنسخة الجديدة.
2. **نشر (Deploy) ← إدارة عمليات النشر ← ✏️ تعديل ← الإصدار: إصدار جديد**
   - التنفيذ باسم: **أنا**
   - من لديه حق الوصول: **أي شخص (Anyone)**
3. احفظ — الرابط بيفضل زي ما هو.

> الحماية بتكون من صفحة تسجيل الدخول جوه النظام (البريد وكلمة المرور من ورقة `Users`).
> اختيار «أي شخص لديه حساب Google» بيمنع النظام يفتح جوه الصفحة وعلى الآيفون.

## تغيير رابط النظام

لو عملت نشر جديد بلينك مختلف: افتح `index.html` وغيّر السطر:

```js
var APP_URL = 'https://script.google.com/macros/s/.../exec';
```

## تثبيت التطبيق

- **أندرويد (Chrome):** افتح الرابط ← ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الكمبيوتر (Chrome / Edge):** أيقونة التثبيت في شريط العنوان.

## لو ظهر زر «فتح النظام مباشرة»

معناه إن النظام ما فتحش جوه الصفحة — غالبًا النشر لسه بالإعدادات القديمة.
راجع خطوة «إعداد Google Apps Script» واعمل **إصدار جديد**.
